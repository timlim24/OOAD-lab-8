
| консюмерів | розподіл партицій | хто простоює |

| 2 | | |
| 3 | | |

## Висновок

- партиція — одиниця паралелізму, консюмерів понад їх кількість марні;
- кожен консюмер рахує вікна лише по своїх партиціях → результати частинні;
- під час rebalance обробка зупиняється.
